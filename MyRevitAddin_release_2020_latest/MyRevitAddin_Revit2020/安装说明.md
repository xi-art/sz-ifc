# MyRevitAddin 安装说明（Revit 2020）

## 本 ZIP 包含文件

| 文件 | 说明 |
|---|---|
| `MyRevitAddin.dll` | 插件主程序（.NET 4.8） |
| `MyRevitAddin.pdb` | 调试符号（崩溃时可定位行号，可删但不建议） |
| `MyRevitAddin.addin` | Revit 插件清单（告诉 Revit 去哪里加载 DLL） |
| `Install_For_AllUsers_2020.bat` | 一键安装脚本（当前用户 + 所有用户目录） |
| `安装说明.md` | 本文件 |

## 一键安装（推荐）

1. **先关闭所有 Revit 2020 窗口**（DLL 被占用时无法覆盖，会导致加载旧代码）
2. 双击 `Install_For_AllUsers_2020.bat`
3. 脚本完成后重新打开 Revit 2020 → 任意项目 → 功能区出现 **「我的工具」** 选项卡即安装成功

## 手动安装

### 只给当前 Windows 用户装

把 `MyRevitAddin.dll / MyRevitAddin.pdb / MyRevitAddin.addin` 三个文件复制到：

```
%APPDATA%\Autodesk\Revit\Addins\2020\
```

（对应实际路径一般是 `C:\Users\<用户名>\AppData\Roaming\Autodesk\Revit\Addins\2020\`）

### 给本机所有 Windows 用户装

把三个文件复制到：

```
%PROGRAMDATA%\Autodesk\Revit\Addins\2020\
```

（一般是 `C:\ProgramData\Autodesk\Revit\Addins\2020\`，需要管理员权限写入）

## 卸载

关闭 Revit → 删除 `%APPDATA%\Autodesk\Revit\Addins\2020\` 下三个同名文件即可。

## 版本 / 系统要求

| 项 | 要求 |
|---|---|
| Revit 版本 | **Revit 2020**（其他版本暂不支持，请切换 csproj 重新编译） |
| .NET 运行时 | 随 Revit 自带 .NET Framework 4.8（一般无需单独装） |
| 操作系统 | Windows 10 / Windows 11 x64 |

## 功能入口

打开 Revit 2020 → 「我的工具」选项卡 → 14 个面板：

- **机电工具**：按系统选中构件 / 表格导入回导 / 按系统拆分模型 / 管件深圳标识
- **房间工具**：生成房间分割线 / 房间缺口检测 / 批量修改房间名称 / 房间名→属性参数 / 重叠房间检测
- **族工具**：内建族转可载入族 / 批量族重命名 / 批量改参数 / 批量建项目参数 / 批量修改构件属性
- **门窗 / 楼板 / 柱工具**：门窗开启面积 / 楼板长宽计算 / 异形柱长宽计算
- 其他：标记工具 / 图纸工具 / 视图工具 / 标高工具 / 分析可视化 / AI 助手 / 测试

详细功能说明见仓库同目录下的 `README.md`。
